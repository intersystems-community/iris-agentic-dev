1. INGRESS — HIS HL7v2 TCP Feed (EnsLib.HL7.Service.TCPService)

   Listens on port 9999, schema 2.5. Forwards all HL7 messages to the router.
   No filtering at this stage.

2. ROUTING — HIS HL7v2 File Feed Router → IRISDemo.HISHL7v2FileFeedRoutingRule

     action:     transform IRISDemo.DTL.HL7Update → send to Readmission Risk Process

3. TRANSFORM — IRISDemo.DTL.HL7Update

   EnsLib.HL7.Message → RRLACESrv.BO.UpdateEncounterRequest
   Critical field: MSH:MessageType.TriggerEvent → UpdateMessageType = "A03"
   This is what lets the BPL branch differently from A01/A08.

4. BUSINESS PROCESS — IRISDemo.BP.ReadmissionRisk.Process

   Steps 1–4 run for every message type (A01, A03, A08):
     [sync]  Update Encounter         → LACE SOAP Operation
     [sync]  Calculate Risk with LACE → LACE SOAP Operation       → RiskScore
     [sync]  Calculate Risk with ML   → Readmission ML Model Consumer → MLReadmissionRisk

     [async] Add Patient to Risk Program → Care Team (workflow task)
     [sync]  Alert Care Team            → Risk Alert Email Operation
