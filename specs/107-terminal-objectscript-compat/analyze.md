## Next Actions

### CRITICAL — Resolve before `/speckit.implement`

**C1 — Constitution IX exception approval**: The plan.md marks Principle IX (Tool Lift
Requirement) as N/A on the grounds that this is an internal-only change. The constitution
requires explicit approval for this exception. Before implementation, either (a) add a
one-line approval statement to plan.md ("Exception approved: `iris_execute` guard is an
internal behavioral guard, not a new MCP tool visible to agents as a new entry in
`tools/list`") or (b) if the tool description change counts as an externally visible agent
interface change, add a lift benchmark task before Phase 6.

### HIGH — Address before Phase 3 begins

**I2 — `W` abbreviation ambiguity**: In ObjectScript, `W` is `Write`, not `While`. `While`
has no standard one-letter abbreviation. Including `W` in the detection keyword list would
produce false positives on every `Write "..."` statement that appears before a `{`. This is
a potential correctness bug in FR-001. Verify the ObjectScript abbreviation table and remove
`W` from the detection keyword list if it maps to `Write`.

**I1 / I3 — docker exec path test setup**: T006 (no-IRIS unit test) and T007 (integration
test) both need to account for the fact that `docker_only=true` causes an HTTP timeout
before docker exec is reached, not an immediate short-circuit. Update T006 to specify how
the test forces the HTTP path to fail fast (very short timeout, or stub returning error).

**U4 — T011 `{}` assertion too weak**: The current `iris_execute` description already
contains `{}` in unrelated content. The T011 assertion must use a phrase that does not
exist until T012 is implemented, e.g., assert for `"TERMINAL_SYNTAX_UNSUPPORTED"` in the
description text.

### MEDIUM — Address before Phase 6 (Polish)

- **U2**: Reconcile 10ms (spec SC) vs 1ms (plan.md) latency budget; add a timing assertion
  or remove the numeric claim.
- **U3**: Clarify how `iris_doc` is invoked in the T014 Rust integration test.
- **U1**: Rewrite FR-002 global subscript clause to match the string-literal tracking
  implementation strategy described in T005.
- **A1**: Add one unit test case for `If (a=(b+c)) {` to pin nested-paren behavior.

### LOW — Can defer to documentation pass

- **U5**: Add `pub` visibility to FR-001 function signature.
- **U6**: Clarify what "cross-reference" means in T015.
