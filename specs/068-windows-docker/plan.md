# Implementation Plan: Windows Docker Cookbook

**Branch**: `068-windows-docker` | **Date**: 2026-07-24 | **Spec**: [spec.md](spec.md)

## Summary

Deliver a minimal Docker image wrapping the existing static musl Linux binary, published to
GHCR on every release. Adds a CI smoke test on `ubuntu-latest` (not `windows-latest` — see
research.md). Documents the Windows Claude Code config in `docs/windows-docker.md`.

No new Rust code. Changes are: `Dockerfile`, `docs/windows-docker.md`, updates to `ci.yml`
and `release.yml`.

## Phases

### Phase 1 — Dockerfile + smoke test (US1, US2)

- `Dockerfile`: two-stage conceptually, but single-stage in practice — CI builds the binary
  separately; the Dockerfile just `COPY`s the pre-built `iris-agentic-dev` (Linux musl) and
  sets `ENTRYPOINT ["/iris-agentic-dev"]` on `distroless/static-debian12`.
- `ci.yml` `docker-smoke` job: build image, run `--version`, send MCP `initialize` via stdin,
  assert valid JSON-RPC response.

### Phase 2 — Release publish (US3)

- `release.yml`: add `docker-publish` job triggered on `v*` tags. Uses `docker/metadata-action`
  for tag strategy (`<version>` + `latest`), `docker/build-push-action` pushing to GHCR.
  Requires `packages: write` permission (already available via `GITHUB_TOKEN`).

### Phase 3 — Documentation (US1)

- `docs/windows-docker.md`: full cookbook — prerequisites, Claude Code MCP config JSON,
  env-var table, `host.docker.internal` caveat for Linux hosts, troubleshooting.

### Phase 4 — Polish

- Verify image size ≤ 20 MB
